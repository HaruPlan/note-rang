Default theme in a calm deep blue. An easy-on-the-eyes neutral backdrop, with deep blue showing up only where something is selected or highlighted.

## How to use

- Pick it from the **Theme tab** in Settings. The whole app's mood changes the moment you select it.
- The accent color (deep blue) can be changed to any color you like, right from the Theme tab. Change it and things like selection highlights and warning backgrounds shift along with it.
- The note paper color (background) isn't handled by this theme — that's the **Background Color** plugin's job.
