지금 보고 있는 메모를, 내가 정해 둔 문구로 감싸서 클립보드에 한 번에 복사해줘요. AI에게 붙여넣을 프롬프트를 만들 때 특히 잘 맞아요.

## 이렇게 써요
- **설정 › 도구 › 복사하기**에서 복사 문구(템플릿)를 미리 적어 둬요.
- 메모 위 툴바의 📋 버튼을 누르면 → 템플릿에 채워진 채로 복사되고 "복사됨" 알림이 떠요. 이제 어디든 붙여넣기(Cmd+V) 하면 돼요.
- 복사 문구 안에 아래 변수를 넣어 두면, 지금 메모 값으로 자동으로 채워져요:

| 변수 | 채워지는 값 |
| --- | --- |
| `{content}` | 메모 본문 전체 |
| `{path}` | 메모 파일이 저장된 경로 |

- 예를 들어 복사 문구를 `아래 메모를 요약해줘: {content}` 로 두면, 버튼 한 번에 "요약해줘 + 내 메모"가 통째로 복사돼요.

## 이런 걸 바꿀 수 있어요
- **복사 문구** — 위 변수를 섞어 원하는 형태로 만들어요. 비워 두면 메모 경로만 복사돼요. `{path}`·`{content}`처럼 아는 변수를 쓰면 입력 아래에 미리보기가 바로 떠서, 메모 창을 열지 않고도 결과를 확인할 수 있어요.

> 「복사 문구로 복사」는 **설정 › 단축키**에서 키 조합을 배정할 수도 있어요.

> 📋 버튼을 어디에 둘지는 **설정 › 외형 › 툴바 배치**에서 드래그로 정해요.
