Write `{{Cmd+C}}` in a note and it renders as a crisp keycap, just like a real key on your keyboard.

## How to use

- Wrap a key name in double curly braces: `{{Cmd+C}}` → turns into a keycap shape.
- Combos work the same way: `{{Ctrl+S}}`, `{{Shift+Tab}}`, and so on.

> 💡 On the line you're currently editing, `{{Cmd+C}}` shows up as plain text. Move the cursor to another line and it turns into a keycap — that's not a bug, it just means you're editing that line right now.
