Resets this note's options — background, font size, opacity, pin, and more — back to the global defaults in one go. Other notes are left untouched.

## How to use

- Press the ↺ button on the toolbar → it asks "Reset this note's options?" first. Confirm and this note's options revert to the global defaults.
- Background, font size, opacity, always on top, all desktops, header collapsed, and preview all reset to their defaults at once.
- Only the option values saved for this note are cleared — other notes aren't affected.

> Where the ↺ button sits is decided by dragging it in **Settings › Appearance › Toolbar Layout**.
