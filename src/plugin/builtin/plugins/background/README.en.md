Change the color of the note paper. Pick a background and the text color automatically adjusts to stay readable.

## How to use

- Press the 🎨 button on the note toolbar to pick a color. Choose from the built-in swatches (Sand, Sage, Ash, Cream) or pick any color you like.
- Text turns dark on a light background and light on a dark background, so it always stays readable.
- The color you pick is saved per note. Turning this plugin off removes the 🎨 button and reverts to the default cream color.
