Insert document starters you use often — meeting notes, dailies, retros — with one button instead of retyping them each time. Things like dates fill themselves in the moment you insert.

## How to use

- **Insert (📑)** — press 📑 on the toolbar to see your saved templates. Pick one and it drops in right where your cursor is (if there's only one template, it's inserted right away).
- **Save (🗃️)** — saves the note you're currently writing as a new template. It only asks for a name; no new window opens.
- Put keywords like these in a template and they're replaced with their actual values at insert time:

| Keyword     | Filled with                            |
| ----------- | -------------------------------------- |
| `{today}`   | Today's date                           |
| `{time}`    | The current time (14:30)               |
| `{title}`   | This note's title                      |
| `{today+7}` | The date 7 days from today             |
| `{cursor}`  | Where the cursor lands after inserting |

There are more keywords beyond these — see the keyword chips in Settings.

## What you can change

- **Templates** — add, edit, duplicate, and reorder template cards. Notes saved with 🗃️ also show up here as new cards.
- **Insert mode** — choose whether templates land at the cursor, get appended to the end of the document, or replace the whole document (a full replace can still be undone with Cmd+Z).
- **Date format** — choose how dates like `{today}` are formatted (2026-07-09 · 2026.07.09 · July 9, 2026).

> Where the 📑 and 🗃️ buttons sit is decided by dragging them in **Settings › Appearance › Toolbar Layout**.
