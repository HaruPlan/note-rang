회의록·데일리·회고처럼 자주 쓰는 문서를, 매번 새로 치지 않고 버튼 한 번으로 불러와요. 날짜 같은 건 넣는 순간 알아서 채워져요.

## 이렇게 써요
- **불러오기(📑)** — 툴바의 📑를 누르면 저장해 둔 틀 목록이 떠요. 고르면 커서 자리에 쏙 들어가요(틀이 하나면 바로 들어가요).
- **저장(🗃️)** — 지금 쓰던 메모를 그대로 새 틀로 저장해요. 이름만 물어보고, 새 창은 뜨지 않아요.
- 틀 안에 아래 같은 키워드를 적어 두면, 불러오는 순간의 값으로 바뀌어요:

| 키워드 | 채워지는 값 |
| --- | --- |
| `{today}` | 오늘 날짜 |
| `{time}` | 지금 시각 (14:30) |
| `{title}` | 이 메모의 제목 |
| `{today+7}` | 오늘부터 7일 뒤 날짜 |
| `{cursor}` | 불러온 뒤 커서가 놓일 자리 |

이 밖에도 여러 키워드가 있어요 — 설정의 키워드 칩에서 볼 수 있어요.

## 이런 걸 바꿀 수 있어요
- **템플릿** — 틀을 카드로 추가·수정·복제·순서 변경해요. 🗃️로 저장한 메모도 여기 새 카드로 들어와요.
- **삽입 방식** — 커서 자리에 넣을지, 문서 끝에 붙일지, 전체를 바꿀지 골라요(전체 교체도 Cmd+Z로 되돌려져요).
- **날짜 형식** — `{today}` 같은 날짜를 어떤 모양으로 채울지 골라요 (2026-07-09 · 2026.07.09 · 2026년 7월 9일).

> 📑·🗃️ 버튼을 어디에 둘지는 **설정 › 외형 › 툴바 배치**에서 드래그로 정해요.
