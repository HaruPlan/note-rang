Keeps this note floating above other windows. It stays visible even while you're using other apps.

## How to use

- Hover over the note to reveal the toolbar. Use the pin (📌) button to turn "Always on Top" on and off.
- While it's on, the note keeps showing above other windows, even when browsing the web or using other apps.
- This setting is saved per note. Turning it off makes the note behave like an ordinary window again.
