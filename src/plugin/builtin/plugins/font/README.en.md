Pick the font your notes are drawn in. From a crisp default face to a handwriting-like serif, you can even pick from **fonts installed on your Mac**.

## How to use

- Pick one in Settings › Appearance › Font. Each row is rendered in its own font, so you can see what it looks like before choosing it.
- The list is split into three groups — **Default** (System, Serif, Monospace), **Korean** (installed fonts that include Korean glyphs), and **Installed Fonts** (everything else).
- A search box appears once you have a lot of fonts. Typing part of a name filters the list — **searching by the Korean name also works** (typing "나눔" finds `NanumGothic`, if the font file embeds a Korean name).
- The font you pick applies to every note.

## Adding new fonts

Install a font on your Mac — double-click the downloaded font file to install it with **Font Book**, and it shows up in the list the next time you open Settings. Nothing to register in the app itself.

## Notes

- Turning this plugin off removes the font picker and falls back to the system default font.
- If you pick a Latin-only font, Korean text still renders in a different font. To draw Korean text in that same font too, pick it from the **Korean** group instead.
