Colors your text like a highlighter. Drag-select some text and pick a color from the little formatting bar that pops up.

## How to use

- **Drag-select** the text, hit the 🎨 (palette) button on the formatting bar, and pick a color: `{{urgent|#f36}}` → **urgent** shows up in that color.
- Re-select a colored span and pick another color to swap it; the **✕ (remove color)** button at the end of the palette row strips it back to plain text.
- Both 3-digit (`#f36`) and 6-digit (`#ff3366`) hex work, so any color you hand-type — `{{urgent|#a1b2c3}}` — is drawn even if it isn't on the palette.

> 💡 On the line you're currently editing, `{{urgent|#f36}}` shows up as plain text. Move the cursor to another line and it turns into a color — that's not a bug, it just means you're editing that line right now.

> 💡 Turn this plugin off and the palette button disappears from the formatting bar too (there's no color syntax left to write).
