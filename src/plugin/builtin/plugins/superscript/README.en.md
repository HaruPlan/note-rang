Shrinks and raises text, like an exponent or a footnote number.

## How to use

- Wrap the character to raise in a pair of `^`: `Area is 3m^2^` → the `2` is raised and shrunk.

> 💡 On the line you're currently editing, `3m^2^` stays visible as-is. Move the cursor to another line and it turns into a superscript — that's not a bug, it's just showing you which line you're editing right now.
