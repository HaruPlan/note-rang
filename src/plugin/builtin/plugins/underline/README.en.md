Markdown has no built-in underline, so this shows underlined text as if it were underlined.

## How to use

- Wrap the text you want underlined in double `++`: `++make sure++` → it gets underlined.

> 💡 On the line you're currently editing, `++make sure++` shows up as-is. Move the cursor to another line and it turns into an underline — that's not a bug, it just means you're editing that line right now.
