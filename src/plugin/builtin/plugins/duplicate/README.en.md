Duplicate the current note — content and settings (opacity, background color, font size, pin, etc.) all included, into a brand-new note. Handy when you want several similar notes.

## How to use

- Hover over a note to reveal its toolbar, then press the Duplicate (⧉) button — a new note with the same content and settings opens.
- The original stays untouched. The new note opens at a default position so it doesn't overlap the original and confuse you.

> Where the ⧉ button sits is decided by dragging it in **Settings › Appearance › Toolbar Layout** (bottom-left by default).
