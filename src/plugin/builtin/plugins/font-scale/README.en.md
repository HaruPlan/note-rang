Make the text in just this note bigger or smaller. Other notes are left untouched.

## How to use

- Press the A− / A+ buttons on the toolbar to shrink or grow this note's text by 10% each time. A "Font ±N%" toast confirms every press.
- The size is saved per note.
- To change the default font size for all notes, use the app settings — the buttons here only touch this one note.

> Where the A−/A+ buttons sit is decided by dragging them in **Settings › Appearance › Toolbar Layout**.
