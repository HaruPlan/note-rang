메모 창을 은은하게 비쳐 보이게 만들어요. 뒤 화면이 살짝 투과돼서, 책상 위 유리 메모지 같은 느낌이 나요.

## 이렇게 써요
- 메모 위에 마우스를 올리면 툴바가 나타나요. 슬라이더를 움직여 투명도(30%~100%)를 맞춰요.
- 이 설정은 메모마다 따로 저장돼요 — 어떤 건 진하게, 어떤 건 흐릿하게 둘 수 있어요.

> 💡 이 플러그인을 끄면 슬라이더가 사라지고 메모는 다시 또렷해져요. 맞춰 둔 투명도는 기억해 두었다가, 다시 켜면 그대로 살아나요.

🍎 macOS에서만 동작해요. 다른 환경에서는 슬라이더가 나타나지 않고 메모는 항상 또렷하게 보여요.
