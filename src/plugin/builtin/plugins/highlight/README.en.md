Highlights important parts like a marker pen, so they stand out.

## How to use

- Wrap the text you want to highlight with double `==`: `==due tomorrow==` → shaded in yellow highlighter.

> 💡 On the line you're currently editing, `==due tomorrow==` shows up as plain text. Move the cursor to another line and it turns into a highlight — that's not a bug, it just means you're editing that line right now.
