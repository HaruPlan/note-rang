## 이렇게 써요
아래처럼 `youtube` 코드블록 안에 링크를 넣으면, 커서가 블록 밖으로 나갔을 때 플레이어로 바뀌어요:

    ```youtube
    https://www.youtube.com/watch?v=dQw4w9WgXcQ
    ```

- `watch?v=…` · `youtu.be/…` · `shorts/…` 링크를 지원해요.
- 플레이어는 화면에 보일 때만 불러와서 가벼워요. 파일에는 링크 글자만 저장돼요.
- 재생은 개인정보를 덜 남기는 도메인(youtube-nocookie.com)에서 이뤄져요.

> 💡 커서가 블록 안에 있을 때는 링크가 그대로 보이고, 밖으로 나가면 플레이어로 바뀌어요. 다시 고치고 싶으면 커서를 블록 안으로 옮기면 돼요.
