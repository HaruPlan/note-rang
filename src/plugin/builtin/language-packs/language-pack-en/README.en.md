Renders the app **in English**. Every sentence the app shows — menus, buttons, notices — has its English version inside this folder.

## How to use

- Pick `English` from the **Language** dropdown in Settings › Appearance › Theme. The settings window refreshes itself right away and switches to English, and every note or list window you open afterwards comes up in English too.
- If you have never picked a language, English is chosen automatically when your computer's language is not Korean.
- This language pack ships with the app, so there is nothing to install — it is already in the list and already on.

## What happens if you turn it off

- `English` disappears from the language choices and the app **falls back to Korean**. Korean is the app's base language and can't be turned off.
- **Open note windows switch to Korean right away** — turning the pack off makes them refresh themselves.
- The **settings window you clicked in, and any open list window, stay in English**, though: text that has been drawn is never repainted. Close and reopen those windows and they come up in Korean.

## Notes

- To use a language other than English, install a language pack plugin. This folder has **exactly the same shape** as one, so it doubles as a living example for authors (see the guide in `docs/plugin/examples/language-pack-en/`).
- If a sentence has no translation, only that sentence falls back to Korean — the screen never breaks as a whole.
