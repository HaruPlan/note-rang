# 플러그인 기능 한눈에

이 플러그인 API로 **무엇을 할 수 있는가**를 스캔 가능한 목록으로 정리한다. 각 항목은 필요한
권한과 [`authoring.md`](./authoring.md)의 해당 절을 가리킨다. 호출별 인자·반환·오류 코드의
정본은 [`api-reference.json`](./api-reference.json)(기계가독)이고, 매니페스트 필드 전수의
정본은 [`manifest.schema.json`](./manifest.schema.json)이다.

권한 모델 요약: 저위험 권한은 **선언만**으로 통과하고, 민감 권한은 **선언 + 사용자 로컬 부여**가
필요하다. `network:<도메인>`·`embed:<도메인>`·`invoke:<대상>`은 값별로 쪼갠 접두 매칭 민감
권한이다. 전체 규칙은 [`authoring.md`](./authoring.md)의 「권한」 절.

## UI — 버튼·메뉴·상태·트레이·팝업 (권한 `ui`)

| 기능               | 호출                                       | 한 줄                                                                                                                                                                                                                                                                               |
| ------------------ | ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 툴바 버튼          | `ui.addToolbarButton`                      | 노트 창 툴바에 버튼을 얹고 클릭 시 동작을 실행한다.                                                                                                                                                                                                                                 |
| 컨텍스트 메뉴 항목 | `ui.addMenuItem`                           | 노트 우클릭 메뉴에 메뉴 전용 항목을 넣는다(`when`으로 조건부 노출, `payload.selectedText`는 `notes:read`가 부여됐을 때만 채워진다). 커뮤니티/사이드로드 플러그인만 표시되고 빌트인은 툴바 버튼과 중복이라 빠진다.                                                                   |
| 선택 액션          | `ui.addSelectionAction`                    | 본문을 선택하면(마우스 드래그·키보드 선택 모두) 뜨는 선택 툴바 맨 끝에 버튼을 얹는다(단축키로도 실행). 표시 조건 `match`는 정규식이 아니라 닫힌 어휘(문자 부류·한 줄 여부·길이 상한)이고 창 안에서 로컬로 판정된다. `payload.selectedText`는 `notes:read`가 부여됐을 때만 채워진다. |
| 상태 아이템        | `ui.addStatusItem` · `ui.updateStatusItem` | 툴바에 텍스트·카운트를 보여주고 창별로 라이브 갱신한다.                                                                                                                                                                                                                             |
| 메뉴바 트레이 항목 | `ui.addTrayItem`                           | 시스템 트레이(메뉴바)에 항목을 얹고 클릭 시 `run`을 실행한다(앱 전역).                                                                                                                                                                                                              |
| 토스트             | `ui.toast`                                 | 창에 일시 알림을 띄운다.                                                                                                                                                                                                                                                            |
| 목록 선택 팝업     | `ui.pickList`                              | 항목 목록에서 하나를 고르는 팝업(항목별 액션 지원).                                                                                                                                                                                                                                 |
| 한 줄·폼 입력 팝업 | `ui.prompt`                                | 텍스트·토글 등 필드로 값을 입력받는 팝업.                                                                                                                                                                                                                                           |

자세한 계약: [`authoring.md`](./authoring.md)의 「ui」 절.

## 에디터 — 인라인 패턴·자동완성·임베드·폰트·삽입 (권한 `editor`, 삽입은 `notes:write`)

| 기능                | 호출                                          | 한 줄                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------------- | --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 인라인 패턴 스타일  | `editor.registerInlinePattern`                | 구분자 사이 구간에 의미 토큰 스타일을 입힌다. `mid`로 세 토막(`{{라벨\|대상}}`)까지 표현하고, `action`으로 클릭 동작(노트 열기·브라우저 열기·없음)을 고른다. `param`을 주면 `close` 앞의 값(`{{글자\|#f36}}`의 `#f36`)을 캡처해 **그 매치의 색**으로 쓴다 — 색마다 등록을 만들 필요 없이 등록 하나로 임의 hex(3·6자리)를 칠한다. 패턴이 화면에 남기는 토막 안에 완전히 들어가는 다른 패턴은 **중첩**으로 함께 렌더된다(색 감싸기 안의 위키링크는 색을 입은 채 클릭도 된다). |
| 자동완성            | `editor.registerCompletion`                   | 트리거 문자열에 후보 목록을 띄운다.                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| 블록 임베드         | `editor.registerBlockEmbed`                   | 매칭 블록을 렌더 뷰로 치환한다. 실제 렌더는 최종 URL 도메인별 `embed:<도메인>` 권한이 별도로 게이트한다.                                                                                                                                                                                                                                                                                                                                                                    |
| 폰트 크기 읽기/쓰기 | `editor.getFontDelta` · `editor.setFontDelta` | 현재 창의 폰트 크기 델타를 읽고 조정한다.                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| 텍스트 삽입         | `editor.insertText`                           | 커서 위치에 삽입(`mode:"cursor"`, 선택이 있으면 대체)하거나 문서 전체를 덮어쓴다(`mode:"replace"`). 본문을 쓰므로 `notes:write`.                                                                                                                                                                                                                                                                                                                                            |

자세한 계약: [`authoring.md`](./authoring.md)의 「editor」 절.

## 노트 읽기/쓰기 (권한 `notes:read` · `notes:all-read` · `notes:write`)

| 기능                | 호출                        | 권한             | 한 줄                                                                        |
| ------------------- | --------------------------- | ---------------- | ---------------------------------------------------------------------------- |
| 현재 노트 읽기      | `notes.current`             | `notes:read`     | 지금 창의 노트 본문·메타를 읽는다.                                           |
| 전체 노트 목록·읽기 | `notes.list` · `notes.read` | `notes:all-read` | 모든 노트의 제목 목록과 본문을 읽는다(현재 노트 읽기와 별도 민감 권한).      |
| 노트 쓰기           | `notes.write`               | `notes:write`    | 임의 노트에 append(비파괴) 또는 overwrite(파괴적, 덮기 전 복구 스냅샷 저장). |
| 노트 복제           | `notes.duplicate`           | `notes:write`    | 현재 노트를 복제해 새 창으로 연다.                                           |
| 노트 옵션 복원      | `notes.resetOptions`        | `notes:write`    | 이 노트의 override(사이드카 메타)를 전역 기본값으로 되돌린다.                |

자세한 계약: [`authoring.md`](./authoring.md)의 「notes」·「전체 노트 읽기」 절.

## 설정·이벤트 (권한 `settings`)

| 기능          | 호출                               | 한 줄                                                                                  |
| ------------- | ---------------------------------- | -------------------------------------------------------------------------------------- |
| 설정 값 읽기  | `settings.get` · `settings.getAll` | 선언한 설정 키의 값을(기본값 병합) 읽는다.                                             |
| 설정 값 쓰기  | `settings.set`                     | 자기 플러그인의 설정 값을 바꾼다.                                                      |
| 생명주기 구독 | `events.on`                        | `settings:changed`(추가 권한 없음)·`note:*`(이름별 `notes:read`) 등 이벤트를 구독한다. |

매니페스트 `settings[]`로 설정 폼 필드를 선언하면 앱 설정 화면에 카드 UI로 렌더된다. 자세한
계약: [`authoring.md`](./authoring.md)의 「설정 필드」·「events」 절.

**설정이 바뀌면 샌드박스는 언제나 다시 선다**(런타임 상태 초기화, 구독·등록 재생성). 다만 열려
있는 노트 창은 더 이상 함께 리로드되지 않는 것이 기본이다 — 툴바 항목·CM 확장·능력을 제자리에서
맞추고, `note:opened`를 다시 보낸다. 무엇이 조정되고 무엇이 여전히 리로드인지는
[`authoring.md`](./authoring.md)의 「재빌드」 절.

## 명령 (권한 `commands`)

| 기능                      | 호출                | 한 줄                                                                                                                                            |
| ------------------------- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 버튼 없는 명령            | `commands.register` | 툴바를 차지하지 않고 단축키로 실행되는 동작을 등록한다. `when`으로 조건부 활성화.                                                                |

## 능력 등록 — 테마·배경·폰트·창·언어팩 (`kind: "capability"` 필수)

능력 플러그인은 매니페스트에 `kind: "capability"`를 선언해야 한다. 각 능력은 스냅샷의 슬롯
하나로 병합된다.

「제공 방법」 열이 **호출이냐 선언이냐**를 함께 담는다 — 능력마다 공급 경로가 다르기 때문이다.
창 컨트롤은 둘 다 되고(매니페스트 선언은 호스트가 같은 게이트·registrar로 `window.register`에
미러링한다 — 결과는 합집합이라 어느 쪽으로 적어도 같다), 언어팩은 대응 호출이 아예 없다:
코드 실행이 필요 없는 데이터라 코어(Rust)가 설치 매니페스트를 직접 스캔해 각 창에 공급한다
(플러그인 샌드박스도 호스트 스냅샷도 경로에 없다).

| 능력      | 제공 방법                                                     | 권한             | 한 줄                                                                                  |
| --------- | ------------------------------------------------------------- | ---------------- | -------------------------------------------------------------------------------------- |
| 테마      | 호출 `theme.register`                                         | `theme`          | 색 토큰 묶음을 등록한다(마지막 등록이 이김).                                           |
| 배경      | 호출 `background.register`                                    | `background`     | 노트 배경을 등록한다(먼저 등록이 이김).                                                |
| 폰트      | 호출 `font.register`                                          | `font`           | 글꼴을 등록한다(합집합).                                                               |
| 창 컨트롤 | 호출 `window.register` · 선언 `contributes.windowControls`    | `window-control` | 투명도·항상 위·모든 데스크탑 같은 창 제어 능력을 선언한다(합집합).                     |
| 언어팩    | 선언 `contributes.translations`(대응 호출 없음 — 코어가 소비) | `i18n`           | 로케일(코드·표시 라벨·문자열 사전)을 공급한다(합집합, 같은 코드끼리는 나중 팩이 이김). |

자세한 계약: [`authoring.md`](./authoring.md)의 「theme · background · font」·「window」·「언어팩」 절.

## 네트워크 (권한 `network:<도메인>`)

| 기능            | 호출            | 한 줄                                                                                                                                              |
| --------------- | --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| https 요청 중계 | `network.fetch` | 호스트가 대신 보내는 https 요청. 권한은 선언한 도메인별 `network:<호스트>`로 정확 매칭되고, SSRF 방어(사설대역·리다이렉트 등)는 백엔드가 소유한다. |

## 브라우저 열기 (권한 `browser:open`)

| 기능      | 호출           | 한 줄                                                                                                                                                         |
| --------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 링크 열기 | `browser.open` | URL을 시스템 기본 브라우저로 넘긴다. 스킴은 `http`·`https`·`mailto`만 통과한다(그 밖은 백엔드가 거부). 인라인 패턴의 `action: "open-url"`도 같은 권한을 쓴다. |

`network:<도메인>`과 달리 도메인별로 쪼개지 않는다 — 여는 주소가 대개 노트 본문에서 오므로 승인 시점에 목록화할 수 없다. 방어는 스킴 제한이다.
